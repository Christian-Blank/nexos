# Paused

Paused tasks are moved into this folder. If a task is restarted, it is moved back to current. If another task is already in current, that task has to be first finished before a paused task can be moved to current. If a task is queued again, it is moved back to backlog to review, reprioritize, and check the build order, before eventually moved to next. Do not move from paused to next. If a task is moved from paused to current, the first step is always to analyze and sanity check past changes to spot any gaps, diffs, or drifts between the plan including paused implementation and the current state of the repository. Do not assume it is still the same state as when the task was paused. The task was most likely paused for a reason to get other work that could not be parallized done first.
