# PLAN‑54 — Deterministic docs generator (CLI reference + README auto‑blocks)

> **Mission:** Generate human‑grade CLI docs **from the live command tree** and keep plugin READMEs in sync via auto‑blocks. Eliminate doc drift with CI gates.

## Outcomes (acceptance criteria)

1. **Live introspection:** `nexoscli-bin` exposes a hidden command:
   - `__introspect clap-json` → prints the full clap `Command` tree as JSON (stable shape).
2. **Docs command:** `nexoscli dev docs commands`:
   - Writes `docs/CLI_REFERENCE.md` from the introspection JSON.
   - Updates **`<!-- BEGIN: AUTO (id=commands) --> … <!-- END: AUTO -->`** blocks in each `plugins/*/README.md` when `--apply-readmes` is set.
   - Supports `--out-md <path>` and `--apply-readmes`.
3. **No drift in CI:** Running `nexoscli dev docs commands --out-md docs/CLI_REFERENCE.md --apply-readmes` on a clean tree **produces no diff**. CI gate fails on drift.
4. **Deterministic formatting:** Sections and command lists are **sorted** (stable ordering).
5. **Strict repo check integration:** `nexoscli dev repo check --strict` (or `dev doctor --ci`) enforces that:
   - All plugins have an AUTO `commands` block.
   - `docs/CLI_REFERENCE.md` is present and up‑to‑date.

## Non‑goals

- Export of a machine catalog (JSON) — that’s PLAN‑55.
- Changing user‑visible CLI behavior (flags, help text). This plan is read‑only generation.

---

## Design

### A. Hidden introspection entrypoint (binary)

Add to `nexoscli-bin` a **hidden** top‑level subcommand:

- **Name:** `__introspect clap-json`
- **Behavior:** Build the *same* root clap `Command` tree as `main()`, then walk it and output JSON with this **stable shape**:

```json
{
  "name": "nexoscli",
  "about": "…",
  "version": "…",
  "subcommands": [
    {
      "path": "dev",
      "about": "Developer utilities",
      "subcommands": [
        {
          "path": "dev init",
          "about": "Initialize .nexoscli/…",
          "usage": "nexoscli dev init [--dry-run] [--yes] [--with-config]",
          "args": [
            {"long":"dry-run","short":null,"kind":"flag","required":false,"default":null,"help":"Show plan only"},
            {"long":"yes","short":null,"kind":"flag","required":false,"default":null,"help":"Apply without prompt"},
            {"long":"with-config","short":null,"kind":"flag",…}
          ]
        }
      ]
    }
  ]
}

Notes:
	•	Include for each arg: long, short, kind (flag | value | multi), required, default, possible_values (when applicable), and help.
	•	Every node must carry a unique path (space‑joined ancestors).

B. Docs generator (dev plugin)

Implement nexoscli dev docs commands that:
	1.	Invokes the binary: __introspect clap-json to obtain the tree.
	2.	Renders docs/CLI_REFERENCE.md with:
	•	Title + top‑level synopsis.
	•	Command Tree (nested bullet list linking to anchors).
	•	One section per top‑level group (e.g., dev, task, rules, …).
	•	For each command: a flags table with columns: Flag, Type, Required, Default, Description.
	3.	When --apply-readmes:
	•	Locates each plugins/<name>/README.md.
	•	Creates or updates the <!-- BEGIN: AUTO (id=commands) --> block with a compact command list for that plugin.
	4.	Sorts commands lexicographically for stable diffs.
	5.	Emits a small JSON envelope via ctx.ok listing written/updated files.

C. Drift control (CI)
	•	Add a CI step (or extend existing) to:

nexoscli dev docs commands --out-md docs/CLI_REFERENCE.md --apply-readmes
git add -A
git diff --cached --quiet

If non‑zero, fail with: “docs drift — run ‘nexoscli dev docs commands …’ and commit.”

D. Dual‑derive alignment (pre‑req check)
	•	While this plan does not enforce #[derive(Args)], the exporter should rely only on clap’s built tree, so it works regardless of derive vs builder. Formal enforcement is in PLAN‑55.

Must‑pass invariants (executable)

must_pass:
  - name: "introspection-works"
    cmd: 'nexoscli __introspect clap-json | jq -e ".name==\"nexoscli\""'
    expect_exit: 0

  - name: "cli-reference-generated"
    cmd: 'nexoscli dev docs commands --out-md docs/CLI_REFERENCE.md --output json'
    expect_exit: 0

  - name: "readme-auto-blocks-present"
    cmd: 'rg -n --glob "plugins/*/README.md" "<!-- BEGIN: AUTO (id=commands) -->" | wc -l'
    expect: ">= 1"

  - name: "docs-no-drift"
    cmd: |
      nexoscli dev docs commands --out-md docs/CLI_REFERENCE.md --apply-readmes
      git add -A && git diff --cached --quiet
    expect_exit: 0
