# Dumped

Folder for any plans that have been abandoned, ditched, forsaken, abandoned, dumped, ... at any state of their life-cycle. This is where dreams go to die, but not to be forgoten. Keep the backlog crisp and effective. Priorities change, and important things will come up again and again. Trust the signal intelligence. And as with your bitcoin harddrive you can always dig through the dump if the value is worth the effort. So default to dump, not to backlog.

## Index
